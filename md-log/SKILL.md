# md-log：会话 Markdown 镜像（参考文档）

> 运行机制：由 pi 扩展 `~/.pi/agent/extensions/md-log.ts` 接管（启用 / 停止 / 每轮写入均为静默扩展代码，不产生模型输出）。本文件仅描述日志文件格式与轮次结构，供阅读与排障，**不作为运行时执行指令**。

## 用户可见输出

由扩展以 UI toast 与状态栏呈现，模型不参与、不播报：

| 时机 | 用户唯一可见内容 |
|---|---|
| 开启 | toast：`📝 已开始记录：<日志绝对路径>` |
| 记录中 | 状态栏：`● 记录中` |
| 停止 | toast：`📝 已停止记录` |

## 日志文件结构

### 头部（开启时写入，仅文件为空或缺省时）

```markdown
# 会话日志

- 开始时间: <YYYY-MM-DD HH:MM:SS>
- 状态: 记录中
```

停止时头部状态改写为 `已停止`，并在文件末尾追加结束标记：

```markdown
---

*会话记录结束于 <YYYY-MM-DD HH:MM:SS>*
```

### 每轮格式

```markdown
---

## 用户：<摘要，≤10 字>

<用户消息原文>

## 助手：<摘要，≤10 字>

<助手最终回复正文（不含思考过程）>
```

## 记录范围

- 用户消息原文逐条记录，以 `/` 开头的命令不记录
- 助手只记录最终文本回复正文，不含思考过程；含工具调用的中间消息不记录
- 开启轮（触发词本身）与停止轮不写入日志
- 始终续写（追加到文件末尾），保留全部既有内容

## 状态文件

`.sessions/.md-log-active` = 当前活动日志的绝对路径，由扩展维护，md-log 恢复与会话状态持久化依赖它。`.sessions/` 已在 git 仓库中自动加入 `.gitignore`。

## 相关

- 停止技能：md-unlog（同为参考文档，扩展统一处理）
- 扩展源码：`~/.pi/agent/extensions/md-log.ts`（命令 `/md-log on|off|<path>`）
